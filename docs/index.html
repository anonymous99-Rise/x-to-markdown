X to Markdown

Chrome 扩展

将你有权访问的单条 X 帖子保存为本地 Markdown 文件，方便阅读、研究和知识整理。

功能特点

📄

精确识别单条帖子

根据 URL 精确匹配当前帖子，不误存回复或推荐内容。

🖼️

可选图片归档

下载帖子图片到本地 images/ 文件夹，导出为 ZIP 包。

⌨️

快捷键支持

按 Alt+Shift+X 直接保存当前帖子。

🔒

本地优先

所有处理在浏览器本地完成，不上传任何内容。

安装步骤

1

下载安装包

点击上方「下载安装包」按钮，获取 dist.zip 文件并解压。

2

打开扩展页面

在 Chrome 地址栏打开 chrome://extensions/。

3

开启开发者模式

页面右上角找到「开发者模式」，将其开启。

4

加载已解压的扩展程序

点击左上角「加载已解压的扩展程序」，选择解压出来的 dist 文件夹。

💡

每次更新后，请回到 chrome://extensions/ 点击扩展卡片右下角的刷新按钮，或重新加载。

快捷键更新后，可能需要刷新帖子页面才生效。

⌨️ 快捷键

在 X 帖子详情页按 Alt+Shift+X 直接触发保存。
如需修改，请打开 chrome://extensions/shortcuts。
