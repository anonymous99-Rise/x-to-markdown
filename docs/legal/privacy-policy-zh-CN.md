# X to Markdown 隐私政策

生效日期：正式发布日（发布前填写）

运营者：王帅

联系邮箱：正式发布前填写专用支持邮箱

扩展仅在用户主动使用时读取当前单条 X 帖子，用于在浏览器本地生成 Markdown 或图片 ZIP。处理内容可能包括帖子作者、账号名、发布时间、正文、链接、图片地址和来源地址。

这些内容不会上传到运营者服务器。扩展不收集账号密码、Cookie、Token 或完整浏览历史，也不出售数据，不用于广告、画像、信用评估或训练 AI 模型。

扩展只在浏览器本地保存“是否下载图片”的偏好。生成的文件由用户通过浏览器下载到自行选择的位置；用户可以通过清除扩展数据或卸载扩展删除本地偏好。

图片仍由用户浏览器向 X 的媒体服务器请求。打开保留远程图片地址的 Markdown 时，阅读器也可能向相关服务器发起请求。

如数据处理方式发生实质变化，我们会更新本政策、商店隐私声明和生效日期，并在需要时取得用户同意。隐私问题请发送至正式发布前填写的支持邮箱；不要在公开 Issue 中提交 Cookie、Token、身份证件或其他敏感信息。
