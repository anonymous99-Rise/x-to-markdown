Product support

先让问题变得可复现。

遇到无法识别、导出失败或图片缺失时，先刷新帖子页面并重试。扩展更新后，旧页面通常需要刷新才能加载最新代码。

提交问题前

  • 确认当前是单条帖子详情页，而不是首页或时间线。
  • 确认 Chrome 和 X to Markdown 已更新到最新版本。
  • 刷新页面后，分别尝试扩展弹窗和 Alt+Shift+X。
  • 如果只有图片失败，先关闭图片下载，确认 Markdown 是否能正常导出。

反馈时请提供

  • 扩展版本和 Chrome 版本；
  • 发生问题的操作步骤；
  • 界面显示的完整错误信息；
  • 不包含私人内容的脱敏截图。
不要提交 Cookie、Token、密码、私信、未公开帖子或身份证件。公开 Issue 中的内容任何人都可能看到。
