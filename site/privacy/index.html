隐私政策

生效日期：2026 年 8 月 16 日 · 运营者：王帅

结论：文章处理在你的浏览器本地完成，我们不接收、出售或分析你的帖子内容。

处理的信息

扩展仅在用户主动使用时读取当前单条 X 帖子，用于生成 Markdown 或图片 ZIP。处理内容可能包括帖子作者、账号名、发布时间、正文、链接、图片地址和来源地址。

处理方式和目的

帖子解析、Markdown 生成、图片整理和 ZIP 打包均在用户设备本地完成，仅用于提供用户主动请求的导出功能。扩展不把帖子内容、Cookie、Token、密码或完整浏览历史上传到运营者服务器。

本地存储

扩展使用 Chrome 本地存储保存“是否下载图片”的偏好。该设置不会离开用户设备，可以通过清除扩展数据或卸载扩展删除。

第三方网络请求

用户访问帖子时，页面由 X 提供。只有用户选择图片归档后，浏览器才会从 X 的图片域名请求当前帖子的图片。若导出的 Markdown 保留远程图片地址，阅读器打开文件时也可能向相应图片服务器发起请求。

数据分享与商业使用

我们不出售用户数据，不将数据用于广告、画像、信用评估或 AI 模型训练，不允许人工读取用户的帖子数据，也不将这些信息提供给第三方。

Limited Use

本扩展对信息的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。数据只用于提供或改进扩展明确说明的单一用途，不用于无关目的。

政策变更与联系

如数据处理方式发生实质变化，我们会更新本政策和 Chrome Web Store 隐私声明，并在需要时取得用户同意。隐私问题请通过支持页面联系。请勿在公开 Issue 中提交 Cookie、Token、身份证件或其他敏感信息。
