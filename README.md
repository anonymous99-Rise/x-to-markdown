# X Read

将你有权访问的单条 X 帖子保存为 Markdown，方便个人阅读、研究和知识整理。

X Read 是本地优先的 Chrome 扩展：不需要账号、后端或数据库，帖子解析、图片下载和归档均在你的浏览器中完成。

> [!IMPORTANT]
> 本项目是格式转换工具，不提供帖子内容，也不代表用户取得了帖子的复制、传播、改编、训练或商业使用授权。请仅处理你有权访问和使用的内容。

## 功能

- 根据当前 URL 精确识别单条帖子，避免误存回复或推荐内容
- 提取作者、用户名、发布时间、正文、来源和帖子图片
- 默认导出 Markdown，并保留网络图片
- 可选择下载原始尺寸图片，导出 Markdown 与 `images/` 组成的 ZIP
- 个别图片失败时保留网络地址并显示失败数量
- 在帖子页面右下角提供快捷保存入口
- 所有处理均在本地完成，不上传帖子内容

当前版本不提供时间线批量抓取、自动遍历、登录或付费绕过、私密内容解锁、视频下载及访问控制规避能力。

## 安装

需要 Node.js 20 或更高版本。

```bash
npm install
npm test
npm run build
```

打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择生成的 `dist` 目录。

打开 `x.com/{username}/status/{id}` 或旧版 `twitter.com` 帖子详情页。你可以在扩展 Popup 中选择是否下载图片，也可以使用页面右下角的“存”按钮。快捷按钮会沿用 Popup 中保存的图片偏好。

## ZIP 结构

```text
username-statusId.zip
├── username-statusId.md
└── images/
    ├── 001.jpg
    └── 002.png
```

## 权限和隐私

- `activeTab`：读取用户当前主动打开的帖子。
- `downloads`：把 Markdown 或 ZIP 保存到本地。
- `storage`：只保存“是否下载图片”的本地偏好。
- `x.com` 和 `twitter.com`：识别、读取当前帖子。
- `pbs.twimg.com`：仅在用户选择图片归档后获取帖子图片。

项目不设置服务器，不收集账号、Cookie、Token、浏览历史或导出内容。导出 Markdown 若保留远程图片，阅读器打开文件时仍可能向 X 图片服务器发起请求。
